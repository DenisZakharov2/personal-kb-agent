# Получение транскрипций YouTube

## Как это работает

Скрипт `collect_youtube.py` с командой `transcripts` скачивает автоматические субтитры (automatic captions) с YouTube через `yt-dlp` в формате `json3`.

### Порядок приоритета языков

1. `ru` — русский (если есть)
2. `en` — английский (fallback)

Если субтитров нет ни на одном из языков — видео пропускается с пометкой "ПРОПУЩЕН (нет субтитров)".

## Формат json3 (паттерн из seed)

Структура ответа YouTube caption tracks в формате `json3`:

```json
{
  "events": [
    {
      "tStartMs": 140,
      "dDurationMs": 2970,
      "segs": [
        {
          "utf8": "вы наверное тоже устали от постоянных\\nлимиты которые"
        }
      ]
    }
  ]
}
```

Скрипт извлекает:
- `tStartMs` — начало сегмента (мс) → преобразует в `[мм:сс]`.
- `segs[].utf8` — текст сегмента.

Сегменты группируются в файл с временными метками:

```
[00:00] вы наверное тоже устали от постоянных | лимиты которые
[00:03] сбивают с работы мешают vibe coding | в этом ролике
```

## Команда

```bash
python3 scripts/collect_youtube.py transcripts
```

Опция `--limit N` ограничивает количество видео за один запуск (по умолчанию все pending).

## Почему не_api YouTube

YouTube Data API требует ключа и имеет квоты. Автоматические субтитры через `yt-dlp` не требуют аутентификации для большинства публичных видео и доступны бесплатно.

## Ограничения

- Не все видео имеют автоматические субтитры.
- Субтитры могут быть неточными (автогенерация).
- Некоторые видео могут требовать аутентификации (возрастной рейтинг, регион).
