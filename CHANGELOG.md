# Changelog

Все заметные изменения в этом проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [0.2.1] - 2026-11-07

### Исправлено
- `rebuild_fts()` теперь индексирует текст заметки (`content`), а не её хеш (`content_hash`) — полнотекстовый поиск работает после перестроения индекса
- Команда `kb-agent import` зарегистрирована корректно (убрано несуществующее обращение к `Typer.registered_commands`)
- Японские символы в комментарии `kb_agent/utils/logger.py` заменены на русские
- Опечатка `conтенте` в системном промпте LLM (`kb_agent/processing/llm_client.py`) исправлена на `контенте`
- Убран мертвый тернарный оператор в `kb_agent/sources/registry.py` для YouTube-источников
- Описание CLI команды `main` приведено к понятному виду

## [0.2.0] - 2026-11-06

### Добавлено
- MCP-сервер с 12 инструментами (read + write через pending-подтверждение)
- Система версионирования промптов с откатом (self-improve)
- Обратная связь и метрики качества (feedback rate/tell/metrics)
- Режим локальной обработки (KB_LOCAL_PROCESSING_MODE)
- Редакция чувствительных полей/источников (KB_REDACT_FIELDS, KB_REDACT_SOURCES)
- Автоматическая генерация Каталог.md и Дайджест.md
- Полнотекстовый поиск через SQLite FTS5
- Сбор из Telegram и YouTube с дедупликацией
- Relevance Gate на основе пользовательского профиля
- Система миграций БД (schema_version)
- 297 тестов (pytest)

### Изменено
- Исправлена логика untrusted_content в MCP (внешний контент = untrusted)
- Исправлен CI workflow для автоматического сбора (восстановление state.db)
- Исправлены ошибки YouTube-сборщика (языки субтитров, raw_hash, mark_processed)
- Добавлена проверка TTL (expires_at) при подтверждении pending-изменений
- Исправлен приоритет загрузки .env файлов
- Исправлено несовпадение заголовков между Vault и SQLite FTS5
- Исправлен расчет score из FTS5 rank
- Расширен список стоп-слов для RelevanceGate
- Добавлена CI-проверка синхронизации config/ и kb_agent/resources/
- Исправлена разметка Markdown в README.md
- Добавлены недостающие переменные в .env.example
- yt-dlp перенесен в основные зависимости, убрана верхняя граница версии
- Удалена зависимость requests (заменена на httpx)
- Очищен корень репозитория (проектные черновики → docs/history/)
- Настроены GitHub Topics из keywords pyproject.toml

### Исправлено
- Подавление ошибок сборщиков (теперь пробрасываются для корректного exit code)
- Сбор старых постов вместо новых в Telegram
- Баги в генераторе каталога и VaultManager (None-safety, utf-8, atomic writes)
- Ложные срабатывания RelevanceGate из-за неполных стоп-слов
- Несовпадение типов промптов между prompts.py и search.py

## [0.1.0] - 2026-XX-XX

### Добавлено
- Базовая архитектура (CLI, Core, Processing, Sources, Storage, Agents)
- Интервью для создания пользовательского профиля
- SQLite схема с FTS5 индексом
- Базовый конвейер сбора и суммаризации
- Команды CLI: ask, search, insights, sources, process, interview
- Конфигурация через Pydantic v2 + .env
- Базовые тесты
